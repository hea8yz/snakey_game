# 🐍 SNAKEY

Современная змейка на Python с глубокой прогрессией, магазином, мини-играми и достижениями. Весь интерфейс нарисован на `tkinter` — **никаких внешних зависимостей**, только стандартная библиотека Python.

**Автор:** [hea8yz](https://github.com/hea8yz)
**Версия:** 1.0 (RELEASE)
**Лицензия:** свободное использование

## 🎮 Что это за игра

SNAKEY — классическая «змейка», доведённая до полноценной игры с прогрессией:

- **Классический режим** — собирай еду, расти, не врезайся в себя и стены
- **10 мини-игр**, у каждой — 4 сложности (как в обычной игре, открываются с тех же уровней) и свои множители:
  - 🍎 **Сбор яблок** — сколько успеешь собрать за отведённое время (90/75/60/45 сек), с препятствиями и проходимыми границами
  - 🧠 **Попробуй запомнить!** — запомни цвет фрукта и найди его среди 8 оттенков; ошибка — поражение
  - 🧺 **Яблочный сбор** — приноси яблоки в зону сбора у нижнего края за 60 секунд
  - 🏹 **Голодные игры** — собери нужное число яблок, пока хищник не догнал; он ускоряется со временем, границы проходимы для обоих
  - ⚡ **Змейка-молния** — скорость растёт каждые 5 секунд, золотая еда (редкая) сбрасывает её к начальной; индикатор скорости в углу
  - 🕳️ **Тоннель** — коридор прокручивается, сужается и изгибается; деньги — за каждую секунду выживания, большой таймер под полем
  - 🕯️ **Свет и тьма** — виден только «фонарик» вокруг головы; раз в 10 секунд он гаснет на 2 секунды, еда в темноте даёт бонус ×2 — фрукты вне фонарика не видны
  - 🧱 **Змейка-строитель** — не растёшь, а строишь стены за очки (клавиша `B` или клик мышью); запри змейку-бродягу, пока она не съела всю еду
  - 🪞 **Зеркальная змейка** — вторая змейка зеркалит повороты; продержись 90 секунд
  - 🔁 **Чередование** — три змейки, управление переключается каждые 5 секунд; неактивные гуляют по всей карте и мешают игроку, не сталкиваясь между собой
- **Экономика**: монеты за очки и мини-игры, множители от сложности и выбранного фона
- **Уровни и EXP**: +1 EXP за каждое очко; чем выше уровень, тем больше нужно EXP; уровни открывают сложности и товары
- **Магазин**: 56 цветов змейки (включая градиентные и «Радугу»), 30 фонов, 31 вид еды, 40 аксессуаров для головы — у каждого товара кнопка **(i)** с описанием, множителями и статистикой
- **120 достижений** с наградами: монеты, эксклюзивные цвета, фоны, еда, аксессуары и даже новая фоновая музыка
- **Воскрешение** один раз за игру за монеты (клавиша `C`) — чем выше счёт, тем дороже

## ⌨️ Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | Движение |
| `P` | Пауза |
| `R` | Рестарт |
| `C` | Воскреситься (1 раз за игру) |
| `B` | Режим стройки (мини-игра «Змейка-строитель») |
| `Esc` | В меню |

## 🚀 Запуск

Нужен только Python 3.8+ (tkinter входит в стандартную поставку):

```bash
git clone https://github.com/hea8yz/snakey_game
cd snakey_game
python snakey_main.py
```

Прогресс (монеты, уровень, покупки, рекорды) сохраняется автоматически в `~/.snakey_save.json`.

## 📦 Сборка в exe

В папке игры есть готовый скрипт `build.bat` — двойной клик, и он:
1. проверит Python и при необходимости сам установит PyInstaller;
2. соберёт `SNAKEY.exe` (один файл, окно без консоли, с иконкой змейки);
3. положит `SNAKEY.exe` прямо в папку игры и уберёт временные файлы сборки.

Получается удобная папка «всё в одном»: исходники, `assets\` и `SNAKEY.exe` рядом —
можно и играть (exe), и запускать из исходников (`python snakey_main.py`), и пересобирать
после обновления кода (снова `build.bat`).

Важные детали:
- **Папка `assets\` должна оставаться рядом с exe** — звуки, иконка и `VERSION` читаются из неё. Это же позволяет моддинг: можно подменять/добавлять свои `.wav` в `assets\sounds\` без пересборки.
- **Пересборка нужна только когда менялся код** (`snakey_*.py`). Звуки/иконку/README можно менять прямо в папке.
- Автообновление знает про exe: в exe-сборке игра не пытается заменить код, а покажет напоминание пересобрать `SNAKEY.exe` через `build.bat`.
- Прогресс (монеты, уровень, рекорды) хранится в `~/.snakey_save.json` — общий и для исходников, и для exe, ничего не теряется.
- **Если exe не появился или окно сборки закрылось мгновенно**: окно `build.bat` всегда остаётся открытым до нажатия клавиши и пишет причину ошибки. Самая частая причина «исчезнувшего» exe — антивирус (Windows Defender иногда молча отправляет только что собранный exe в карантин: проверь *Безопасность Windows → Журнал защиты* или добавь папку игры в исключения). Также убедись, что Python установлен с галочкой *Add python.exe to PATH*.

## ⚙️ Особенности

- **4 сложности** — Обычная, Средняя (уровень 5), Сложная (10, смертельные стены), Экстремальная (20, высокая скорость, стены, ядовитые фрукты, ×2.5 к монетам)
- **Ползунок сложности** под полем — переливающиеся сегменты в цветах сложности, под ними множители монет/EXP и все усложнения режима; интерфейс меняется вместе со сложностью
- **Плавное управление** — очередь ввода на 2 хода: повороты не теряются и не «съедаются» между тиками
- **Анимации еды** — плавное появление фруктов без нагрузки на ПК
- **Режим для слабых ПК** — галочка в настройках упрощает графику и отключает анимации, не трогая механики
- **Выбор размера окна** в настройках (окно всегда открывается по центру экрана)
- **Оптимизация**: кэши цветов и шрифтов, пулы объектов, статичное поле рисуется один раз — стабильные ~0.16 мс на игровой тик, без микрофризов
- **Единый современный стиль**: скруглённые кнопки, переливающиеся градиентные фоны, анимации наведения
- **Фоновая музыка и звуки без авторских прав**: шесть треков (классика, ретро, пиксель, космос, фанк, аркада — новые открываются за достижения), музыка играет по кругу, выбор трека в настройках, клики кнопок, поедание, смерть, победа, покупка, повышение уровня — в настройках есть слайдеры громкости музыки и звуков, а также беззвучный режим
- **Иконка игры** — минималистичная зелёная змейка, генерируется автоматически
- **Update log** прямо в меню — вся история изменений с версии 0.1 (открывается одним кликом)
- **Автообновление** — игра сама проверяет репозиторий на GitHub при запуске и обновляет файлы, если вышла новая версия (отключается в настройках)
- **Всплывающие окна без рамок ОС**: своя шапка с перетаскиванием, закрытие ✕ или Esc

## 📁 Структура проекта

```
snakey_game/
├── snakey_main.py       # точка входа: App, окна, запуск (python snakey_main.py)
├── snakey_content.py    # константы: сетка, палитра, товары, сложности, достижения, CHANGELOG
├── snakey_save.py       # сохранение/загрузка, достижения, уровни и EXP
├── snakey_assets.py     # генерация звуков и иконки, SoundManager
├── snakey_utils.py      # кэши цветов, градиенты, скруглённые фигуры
├── snakey_drawing.py    # отрисовка еды и аксессуаров
├── snakey_widgets.py    # RoundButton, GradientBG, базовый Screen
├── snakey_menu.py       # главное меню
├── snakey_shop.py       # магазин
├── snakey_settings.py   # настройки
├── snakey_minis.py      # вкладка мини-игр (10 карточек с выбором сложности)
├── snakey_minigames.py  # логика мини-игр (MinigameMixin)
├── snakey_achievements.py # достижения
├── snakey_game.py       # игровой экран (классический режим)
└── assets/
    ├── sounds/          # wav-звуки (генерируются автоматически, если удалить)
    └── images/          # иконка игры
```
